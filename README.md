截图工具面向日常截图、录屏和重复性桌面操作场景，提供从区域选择、内容保存到自动化执行的一体化体验。它支持 macOS 和 Windows，可在后台通过系统托盘或菜单栏快速唤起。

## 功能

- 区域截图：框选截图区域，使用放大镜精确定位，并可拖动边框调整选区。
- 常驻选区：保存一个常用区域，在屏幕上显示选区指示框。
- 录屏：录制当前选区或主屏画面。macOS 输出 MOV，Windows 输出 MP4。
- 自动化：按顺序执行模拟点击、键盘输入、等待、截图和录屏，可拖动步骤排序、复制脚本，并设置循环次数。
- 快捷操作：支持全局截图快捷键、录屏快捷键和自动化脚本快捷键。
- 文件管理：自定义保存目录、文件名前缀和自增编号。
- 系统集成：支持系统托盘、窗口置顶，以及保存完成后定位文件。
- 外观：支持浅色、深色和跟随系统，自动保存主题选择。

## 使用方式

### 截图

1. 打开应用，点击「框选区域」。
2. 在屏幕上拖动鼠标框选需要截图的区域。
3. 点击「立即截图」，图片会保存到设置的目录。
4. 如果需要使用整个主屏，点击「使用全屏」。

选区指示框显示后，可以拖动边框调整大小，拖动尺寸标签移动选区。在主窗口按 `Esc` 可清除当前选区。

### 录屏

1. 先选择截图区域，或使用全屏区域。
2. 点击「开始录屏」开始录制。
3. 点击「停止录屏」结束录制，视频会保存到设置的目录。

录屏默认仅保存画面，不录制声音。如需声音：

1. 在「设置 → 音频来源」打开「录制音频」。
2. 点击设备所在行选择来源，默认选中系统声音，也可选择内置麦克风、USB 麦克风等输入设备；每次录屏使用一个音频来源。
3. 设备插拔后，点击「刷新设备」更新列表。

开关和设备选择会自动保存，关闭开关不会清除已选设备。更改从下次录屏生效，手动及自动化录屏共用此设置。当前版本只支持主显示器。

macOS Intel 最低支持 10.15，Apple Silicon 最低支持 macOS 11；录制系统声音需要 macOS 13 或更新版本。使用麦克风时需允许麦克风访问。Windows 使用麦克风录制时，需在系统隐私设置中允许桌面应用访问麦克风。

### 切换主题

在「设置 → 外观」中选择浅色、深色或跟随系统，选择后立即生效并自动保存。跟随系统时，应用会随系统明暗模式切换。

### 设置保存位置和文件名

在设置中选择保存目录，并填写文件名前缀。截图和录屏文件会使用此前缀加自增编号命名。

### 使用自动化

1. 打开「自动化」页面并新建脚本。
2. 添加需要执行的步骤：模拟点击、键盘输入、等待、执行截图或执行录屏。
3. 按需要拖动步骤调整顺序。如需脚本开始/停止快捷键，在编辑器中点击「录制」并按下组合键。
4. 点击「保存脚本」，保存步骤及脚本快捷键。
5. 回到首页，在脚本卡片中选择「单次执行」「循环执行」或「指定次数」，点击「开始执行」。

模拟输入受系统权限限制。普通权限运行的应用无法控制管理员权限窗口或系统安全桌面。

### 后台运行

关闭主窗口时，应用会询问是隐藏到菜单栏（macOS）／最小化到托盘（Windows），还是退出应用。勾选「记住我的选择，不再询问」后，后续关闭将直接执行该选择；未勾选时每次关闭都会询问。

隐藏后，应用仍可通过全局快捷键、菜单栏或托盘使用。需要彻底退出时，可通过菜单栏或托盘菜单退出。

## 安装方式

### 直接安装

前往 [GitHub Releases](https://github.com/milletlovemouse/screen-capture-tool/releases/latest)，下载与系统及处理器架构匹配的安装包并完成安装：

- macOS：打开 `.app` 应用，或使用提供的 DMG 安装。
- Windows：运行 `.exe` 安装程序，按向导完成安装。

Windows 安装时如果系统提示安装 WebView2，请按提示完成安装。应用需要 WebView2 才能正常显示界面。

### 从源码运行

从源码运行需要 Node.js 24、pnpm 10 和 Rust stable。

macOS 还需要安装 Xcode Command Line Tools；Windows 还需要安装 Visual Studio Build Tools 的「使用 C++ 的桌面开发」和 Windows SDK。

```sh
pnpm install --registry https://registry.npmjs.org
pnpm tauri dev
```

公司内部 npm 镜像可能缺少 Tauri CLI 的平台二进制，安装依赖时请使用公共 npm 源。

## 安装后无法使用

### macOS 无法截图或录屏

打开「系统设置 → 隐私与安全性」，为本应用授予以下权限：

- 「屏幕录制」：用于截图和录屏。
- 「辅助功能」：用于模拟鼠标点击、键盘输入和部分自动化操作。

授权后完全退出并重新打开应用。如果应用不在权限列表中，可以点击列表下方的 `+` 手动添加应用。

如果系统设置中已经开启权限，但应用内仍显示未授权，请先从菜单栏彻底退出应用，再在终端重置权限记录：

```sh
tccutil reset ScreenCapture com.screencapture.tool
tccutil reset Accessibility com.screencapture.tool
```

重置后重新打开应用，分别点击屏幕录制和辅助功能的「请求权限」，并在系统设置中重新开启。以上命令只会清除旧的权限记录，不会自动授予权限。

### macOS 打开时提示应用已损坏或无法验证开发者

如果应用来自浏览器下载，系统可能会阻止首次打开。确认应用来源可信后，在终端执行：

```sh
xattr -dr com.apple.quarantine /path/to/ScreenCaptureTool.app
open /path/to/ScreenCaptureTool.app
```

也可以在「系统设置 → 隐私与安全性」中允许本次打开。

### Windows 应用无法打开或界面空白

安装或修复 Microsoft Edge WebView2 Runtime，然后重新启动应用。Windows 安装器通常会自动引导安装 WebView2。

### Windows 无法截图或录屏

- 确认系统为 Windows 10 1903 及以上或 Windows 11。
- 更新显卡驱动，并确认系统媒体编码组件可用。
- Windows N 版本需要安装 Media Feature Pack。
- 受保护的视频或窗口可能无法被系统捕获。
- 当前版本只支持主显示器。

### 自动化点击或键盘输入无效

请为应用授予系统要求的辅助功能或输入权限，并确认应用与目标窗口具有相同权限级别。普通权限应用无法操作管理员权限窗口或 UAC 安全桌面。

### 快捷键不生效

检查快捷键是否与其他应用冲突，并确认应用仍在系统托盘或菜单栏中运行。设置页的快捷键录制完成后立即生效；脚本快捷键需点击「保存脚本」后生效。如果注册失败，请更换未被系统或其他应用占用的组合键。

### 录屏没有声音

- 确认已在「设置 → 音频来源」打开「录制音频」，并选择正确的设备；更改后需重新开始录屏。
- 录制系统声音时，确认系统正在播放声音；macOS 需要 13 或更新版本。
- 录制麦克风时，检查系统麦克风权限，并确认所选设备已连接、系统输入电平正常。Windows 还需允许桌面应用访问麦克风。
- 使用 iPhone 连续互通麦克风时，检查手机端连接状态及蓝牙、Wi-Fi 是否正常，必要时重新连接设备后刷新列表。

### 录屏文件无法播放或时长异常

录屏结束后请等待文件保存完成再打开。Windows 录屏依赖系统媒体编码组件，录制奇数尺寸区域时会向内裁剪最多一个像素，以满足 H.264 的尺寸要求。

如果问题仍未解决，请先退出应用并重新打开，再确认系统版本、应用版本和相关权限状态。
